# Sources média privées

Ce dossier décrit le sas d'entrée de la médiathèque. Il ne contient aucun master ni preuve juridique.

- `sources/` décrit où déposer temporairement un master autorisé pendant son traitement. Son contenu réel reste hors Git et hors bundle Expo.
- Les contrats, factures, licences et consentements restent dans l'espace privé choisi par Nexelf. Le manifest conserve uniquement une référence interne non secrète.
- Les variantes approuvées sont copiées dans `assets/media/derivatives/` ou publiées sur le stockage média prévu par l'architecture.

Ne jamais placer ici de secret, URL signée, document d'identité, consentement nominatif ou photographie dont les droits ne sont pas établis.
