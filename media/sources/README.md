# Dépôt temporaire des masters

Le dossier représente une étape du workflow, pas un stockage de production.

1. Conserver le master dans un espace privé avec contrôle d'accès.
2. Lui attribuer l'identifiant sémantique prévu dans le manifest.
3. Vérifier provenance, licence, consentement et restrictions avant toute conversion.
4. Recadrer, retirer les métadonnées inutiles et générer uniquement les variantes nécessaires.
5. Publier les dérivés approuvés, puis supprimer toute copie de travail locale.

Les masters réels sont ignorés par Git. Seul ce README est versionné.
